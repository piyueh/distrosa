# Comparing and Error Analysis against the Analytical Sensitivity of 1D Gaussian

## Run and Get Results

```bash
$ python main.py
```

This command will create the `figs` directory and save the result data in it.
The computation time should be less than 5 seconds when using a NVIDIA GeForce RTX 
4070 GPU.

## Plot

```bash
$ python plot.py
```
This command will make 4 plots and save them in the `figs` directory.
